the nc (netcat) is a simple utility that can be used to connect to a server and send data to it.
is a communication tool that used the TCP or UDP protocol to send and receive data over the network. 
WHAT IS DO:
	- it can be used to connect to a server and send data to it.
	- it can be used to listen for incoming connections on a specific port.
	- it can be used to create a simple chat server or client.
	- it can be used to test the connectivity of a server or a network.
	- it can be used to transfer files between two machines.
IN OUR CASE:
	- we use it to connect to our server and send data to it.
	-> thats happend by the command nc -C localhost 1024
	+ nc is the command to run netcat to do:
	   - use TCP protocol (default).
	   - do the 3 handshake (SYN, SYN-ACK, ACK) to establish a connection between the client and the server.
	   - connect to the server running on localhost (127.0.0.1)
	   - connect to the server on port 1024.
	+ -C
	   - is used to add the \r\n at the end of each line you send to the server(waiting the message form the cleint).
	+ localhost
	   - is the hostname of the server you want to connect to.
	   because when we create the server by the port 1024 on our machine (localhost)
	   	 -> we can connect to it by the hostname (localhost) on \nc\ or by the IP address(127.0.0.1) on the browser.
	+ 1024
	   - is the port number of the server you want to connect to.
